# Meta WhatsApp Cloud API Verification Register

This register documents key Meta Cloud API behaviors, field names, rate limits, and billing structures. Any unconfirmed assumptions must remain marked `unverified` until checked against live Meta API endpoints or Meta's official documentation index (`https://developers.facebook.com/documentation/business-messaging/whatsapp/llms.txt`).

## Detailed Notes & Implementation Directives

### 1. Billing & Rate Structure (MV-01)
- **Constraint:** Rates and free-allowance scopes must be completely dynamic.
- **Data Model:** Create `workspace_rate_cards` table allowing administrators to import or edit country/category rates.
- **Allowance Scope:** Provide a configurable switch in `waba_configs`:
  - `allowance_scope: 'phone_number' | 'waba'` (default: `'waba'`)
  - `free_service_messages_monthly: number` (default: `1000`)

### 2. Free Entry Point (FEP) Mechanics (MV-02)
- **Important Distinction:** FEP does **not** grant unlimited freeform messaging beyond 24 hours. The customer service window remains 24 hours from the customer's last inbound message. FEP only zeros the financial cost of messages dispatched within that 72h timeframe.
- **Webhook Location:**
  ```json
  "messages": [
    {
      "from": "14155552671",
      "id": "wamid.HBgL...",
      "timestamp": "1731234567",
      "type": "text",
      "referral": {
        "source_url": "https://fb.me/...",
        "source_type": "ad",
        "source_id": "1234567890",
        "headline": "Special Offer",
        "body": "Chat with us"
      }
    }
  ]
  ```

### 3. Template Lifecycle Webhooks (MV-03)
- Listen for `message_template_status_update`.
- If a template's category is downgraded or changed by Meta (e.g., from `UTILITY` to `MARKETING`), update the database immediately to prevent inaccurate cost forecasting.

### 4. Error Codes & Retry Guidance (MV-05)
| Code | Category | User-Facing Message | Retryable? | Recommended Action |
| :--- | :--- | :--- | :---: | :--- |
| `131047` | Window Closed | Customer care window expired (24h limit). | ❌ No | Switch composer to pre-approved WhatsApp Template. |
| `131049` | User Throttled | Message throttled by Meta to protect user experience. | ❌ No | Do not retry immediately; attempt alternate channel. |
| `130429` | Rate Limit | Cloud API throughput threshold reached. | ✅ Yes | Exponential backoff (retry after 2s, 4s, 8s). |
| `131056` | Pair Rate Limit | Too many messages sent to this recipient in a short window. | ✅ Yes | Queue for retry after 60 seconds. |
| `131026` | Undeliverable | Number not on WhatsApp or unable to receive. | ❌ No | Mark contact invalid/undeliverable. |
| `132000` | Template Missing | Template name not found in Meta WABA. | ❌ No | Re-sync templates from Meta Graph API. |
| `132001` | Param Mismatch | Parameter count does not match template placeholders. | ❌ No | Inspect required variables in template configuration. |
| `132012` | Media Format | Header media type or aspect ratio rejected. | ❌ No | Check media format guidelines (JPG/PNG/PDF/MP4). |
| `190` | Auth Revoked | Access token expired or permissions revoked. | ❌ No | Trigger admin notification to refresh System User token. |
